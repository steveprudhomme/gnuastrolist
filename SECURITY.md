# Politique de sécurité

Le projet est un prototype sans engagement de correction ni audit de sécurité
externe. Utiliser la dernière version disponible et vérifier les dépendances
avant de distribuer une version.

Ne jamais publier de secrets, de chemins personnels ou de coordonnées privées
dans une issue. Utiliser le signalement privé de vulnérabilités GitHub s'il est
activé sur le dépôt. Sinon, demander au mainteneur un canal confidentiel sans
révéler les détails exploitables; aucun canal privé n'est présumé actif.

Un rapport utile indique version/commit, plateforme, étapes minimales, impact
et exemple anonymisé. Après correction et coordination avec l'auteur du
signalement, documenter la correction et les versions concernées.

Le contrôle en lecture seule du 17 novembre 2026 constate le signalement privé
GitHub désactivé et `main` non protégée. Voir [le relevé](docs/GOUVERNANCE_VERIFIEE.md).
Demander un canal confidentiel au mainteneur sans publier les détails sensibles.
