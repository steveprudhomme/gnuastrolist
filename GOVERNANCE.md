# Gouvernance

Le mainteneur principal est [Steve Prud'homme](https://github.com/steveprudhomme).
Les contributions, discussions et décisions passent par les issues et demandes
d'intégration du dépôt. Aucun délai de réponse n'est garanti.

Le cycle de contribution suit Goal / Produce / Submit / Wait / Repeat décrit
dans CONTRIBUTING.md. Une évolution d'architecture, de méthode scientifique,
de licence ou de contrat de données demande une décision documentée dans
`docs/architecture/decisions/`. Une décision précise contexte, options, choix,
conséquences et validation.

Les modifications non triviales doivent être revues avant fusion. Le mainteneur
documente sa propre revue lorsqu'aucun autre relecteur n'est disponible. Une CI
verte ne constitue pas à elle seule une validation scientifique.

Les protections de branche, les contrôles requis et le signalement privé de
vulnérabilités sont des réglages GitHub à vérifier séparément avant publication;
leur présence n'est pas garantie par ces fichiers. Les tags `vMAJOR.MINOR.PATCH`
désignent uniquement les versions réellement publiées.

Le [relevé ECC-I du 17 novembre 2026](docs/GOUVERNANCE_VERIFIEE.md) indique
les réglages réellement observés, leurs limites et les décisions du propriétaire
encore nécessaires. La publication du lot autonome n’autorise aucune fusion.
